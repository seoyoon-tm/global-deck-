## 빌드

Node와 Chrome이 필요합니다. 설치는 따로 없습니다.

```bash
node overflow_check.js   # 슬라이드별 오버플로 측정. 720px 슬라이드 기준 안전선 670
node qa_png_v4.js        # 슬라이드별 PNG 검수본 생성 (_qa_v4/)
node pdf_v4.js           # PDF 빌드
```

`overflow_check.js`는 각 슬라이드에서 가장 아래로 내려간 요소의 좌표를 잽니다. **덱을 고친 뒤에는 반드시 실행**해 주세요. 670을 넘으면 내용이 푸터를 침범합니다.

PDF를 뷰어에서 열어 둔 채로 빌드하면 덮어쓰기가 막힙니다. 이때는 `_fix.pdf`로 저장되고 안내가 나옵니다.
